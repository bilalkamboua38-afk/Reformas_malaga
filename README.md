# Reformas Extremas | Costa del Sol

Landing page oficial para servicios de reformas integrales y arquitectura en Málaga, Marbella y Costa del Sol.

## 🚀 Despliegue en Vercel

Este proyecto es un frontend estático optimizado con HTML5, Tailwind CSS y Google Fonts.

### Estructura
- `index.html`: Página principal con calculadora de presupuesto, catálogo de servicios, opiniones, FAQ y formulario de contacto.
- `vercel.json`: Configuración de enrutamiento estático para Vercel.
- `arquitectura_conversi_n_mediterr_nea/DESIGN.md`: Especificaciones de diseño y tokens de estilo.
- `reformas_extremas_web_oficial_m_laga_y_costa_del_sol_1/`: Plantillas y recursos gráficos de referencia.
